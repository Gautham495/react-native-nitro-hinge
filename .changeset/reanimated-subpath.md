Add `react-native-nitro-hinge/reanimated` with `useAnimatedHinge()`, `useAnimatedHingeAngle()`, `addHingeWorkletListener` and `addHingeAngleWorkletListener`. The shared values update on the UI thread without going through JS. `react-native-reanimated` 4.4 or later and `react-native-worklets` 0.9 or later are optional peer dependencies, and the main entry doesn't import them.

Add `react-native-nitro-hinge/reanimated` with `useAnimatedHinge()`, `useAnimatedHingeAngle()`, `addHingeWorkletListener` and `addHingeAngleWorkletListener`. The shared values update on the UI thread without going through JS. `react-native-reanimated` and `react-native-worklets` are optional peer dependencies, and the main entry doesn't import them.
